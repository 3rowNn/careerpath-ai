# ชุดเก็บข้อมูลผู้ใช้จริง — CareerPath AI

> path ในเอกสารนี้เทียบกับโฟลเดอร์ `datasets/real_users_kit/`

ใช้วัดว่าโมเดลแนะนำอาชีพถูกแค่ไหนกับ**คนทำงานจริง** (การประเมินชั้นที่ 4) — ไม่บังคับ ระบบทำงานได้แม้ไม่มีข้อมูลนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `make_google_form.gs` | สคริปต์สร้าง Google Form ครบทุกข้อของแบบประเมิน (รอบที่ 4: 76 ข้อ) + หน้ายินยอม + คัดกรอง + เลือกอาชีพได้ครบ 910 อาชีพ (กลุ่ม → อาชีพ) |
| `template.csv` | ถ้าจะเก็บผ่าน Excel/Google Sheets แทน Form (หัวคอลัมน์เดียวกับที่ Form export) |
| `import_responses.py` | ตรวจและนำเข้า CSV → `datasets/real_users/labels.jsonl` |
| `occupations_all.csv` | 910 อาชีพของโมเดล + รหัส O*NET (ใช้หารหัสตอนกรอก template หรือเติม needs_mapping) |
| `occupations_shortlist.csv` | ชื่อภาษาไทยของ 55 อาชีพที่พบบ่อย — แสดงในฟอร์มคู่กับชื่ออังกฤษ (เพิ่มได้ แล้วรัน `build_kit.py` ใหม่) |
| `build_kit.py` | สร้าง `.gs` และ `template.csv` ใหม่จาก `question_bank_short.csv` |

## 1. สร้าง Google Form (ครั้งเดียว ~2 นาที)
1. เปิด https://script.google.com → **New project**
2. ลบโค้ดเดิม วางเนื้อหาทั้งหมดของ `make_google_form.gs` → กด 💾
3. เลือกฟังก์ชัน `createForm` → **Run** → อนุญาตสิทธิ์ (ครั้งแรกจะเตือน "unverified app" เพราะเป็นสคริปต์ของคุณเอง → Advanced → Go to …)
4. ดู **Execution log** จะได้ 2 ลิงก์: ลิงก์ส่งให้ผู้ตอบ และลิงก์แก้ไขฟอร์ม
5. เปิดลิงก์แก้ไข ลองกด Preview กรอกเองสัก 1 รอบ

> ถ้าใช้บัญชีมหาวิทยาลัย (Workspace) ฟอร์มอาจบังคับให้ผู้ตอบล็อกอิน — ปิดได้ที่ Settings → Responses → Restrict to users in …

### ผู้ตอบเลือกอาชีพอย่างไร
เลือก 2 ขั้น: **กลุ่มอาชีพ** (22 กลุ่ม ชื่อไทย) → ฟอร์มพาไปหน้าของกลุ่มนั้น → **dropdown อาชีพในกลุ่ม** (ครบทั้ง 910 อาชีพ)
ชื่ออาชีพเป็นภาษาอังกฤษตาม O*NET (55 อาชีพที่พบบ่อยมีชื่อไทยกำกับ) · สายไอทีอยู่กลุ่ม 15 (36 อาชีพ)
หาไม่เจอ → เลือก "ไม่แน่ใจ / หาไม่เจอ" แล้วพิมพ์ชื่อตำแหน่งเอง

## 2. ใครควรกรอก
- ✅ **คนที่ทำงานอยู่แล้ว** ในตำแหน่งปัจจุบัน **1 ปีขึ้นไป** (ระบบถือว่าอาชีพที่ทำอยู่ = คำตอบที่ถูก)
- ❌ นักศึกษาที่ยังไม่ทำงาน — ฟอร์มจะจบให้อัตโนมัติ เพราะไม่มีอาชีพจริงให้เทียบ
- **กระจายอาชีพ** สำคัญพอ ๆ กับจำนวน — ถ้าทุกคนเป็น developer จะวัดได้แค่อาชีพเดียว
  ควรมีสายที่ทดสอบ persona แล้วโมเดลอ่อน: PM, Sales, บัญชี, IT Support, System Analyst
- จำนวน: กี่คนก็ใช้ได้ · 30 คนขึ้นไประบบจะเสนอน้ำหนัก Ensemble ใหม่

### ข้อความชวนกรอก (คัดลอกไปใช้ได้)
> สวัสดีครับ ผมกำลังทำโปรเจกต์ AI แนะนำอาชีพ อยากขอเวลาประมาณ 10 นาที ช่วยตอบแบบสำรวจทักษะของคนทำงานจริงครับ
> ใช้วัดว่าโมเดลแนะนำอาชีพได้ถูกต้องแค่ไหน **ไม่เก็บชื่อหรืออีเมล** · เหมาะกับคนที่ทำงานในตำแหน่งปัจจุบันมา 1 ปีขึ้นไป
> [ลิงก์ฟอร์ม] — ขอบคุณมากครับ 🙏

## 3. นำเข้าคำตอบ
1. ในฟอร์ม → แท็บ **Responses** → ⋮ → **Download responses (.csv)** (หรือ Link to Sheets → File → Download → CSV)
2. วางไฟล์ไว้ใน `datasets/real_users/` (โฟลเดอร์นี้ไม่ขึ้น git)
3. รันจากโฟลเดอร์โปรเจกต์:
   ```bash
   backend/.venv/bin/python datasets/real_users_kit/import_responses.py datasets/real_users/responses.csv --dry-run   # ตรวจก่อน
   backend/.venv/bin/python datasets/real_users_kit/import_responses.py datasets/real_users/responses.csv             # นำเข้าจริง
   ```
4. คนที่เลือก "ไม่แน่ใจ / หาไม่เจอ" แล้วพิมพ์ชื่อตำแหน่งเอง จะอยู่ใน `needs_mapping.csv` → หารหัสใน `occupations_all.csv`
   ใส่ในคอลัมน์ `code` แล้วรันซ้ำพร้อม `--mapping datasets/real_users/needs_mapping.csv`
5. ดาวน์โหลด CSV ใหม่แล้วรันซ้ำได้เรื่อย ๆ — คนที่นำเข้าแล้วจะไม่ถูกนับซ้ำ

## 4. ดูผล
```bash
cd datasets/ml && ../../backend/.venv/bin/python evaluation/evaluate.py
```
หรือ `GET /api/evaluation` → ส่วน `real_users` (top1, top5, ผลแยกตามโมเดล, น้ำหนัก Ensemble ที่เสนอเมื่อ ≥30 คน)

## ข้อจำกัดที่ควรเขียนในรายงาน
- อาชีพที่ทำอยู่ ≠ อาชีพที่เหมาะที่สุดเสมอไป
- ผู้ตอบคือคนที่เราชวนได้ (ไม่ใช่กลุ่มตัวอย่างสุ่ม) → ผลอาจเอนไปทางสายที่เรารู้จัก
- คนตอบแบบประเมินตัวเอง (self-report) อาจให้คะแนนตัวเองสูง/ต่ำกว่าจริง
